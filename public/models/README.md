# Campus GLB Models

GLB files are intentionally not committed because they are large binary assets.
Place the shared model files in this directory before running the app.

Required paths:

| Building | File path |
| --- | --- |
| 진리관 | `public/models/truth-hall.glb` |
| 미래관 | `public/models/future-hall.glb` |
| 상상관 | `public/models/sangsang-hall.glb` |
| 우촌관 | `public/models/woochon-hall.glb` |
| 탐구관 | `public/models/exploration-hall.glb` |
| 학송관 | `public/models/haksong-hall.glb` |
| 상상큐브 | `public/models/sangsang-cube.glb` |
| 상상빌리지 | `public/models/sangsang-village.glb` |
| 인성관 | `public/models/insung-hall.glb` |
| 연구관 | `public/models/research-hall.glb` |
| 창의관 | `public/models/creativity-hall.glb` |
| 지선관 | `public/models/jiseon-hall.glb` |
| 학군단 | `public/models/rotc.glb` |
| 낙산관 | `public/models/naksan-hall.glb` |
| 공학관A/B동 | `public/models/engineering-hall.glb` |

In the browser, these files are loaded from `/models/<file-name>.glb`.
